## 追加：把"靶侧/连续态侧误差解耦"形式化（承接上条，用户要求详细展开）

**核心澄清：解耦不是"减小误差"，而是"使误差可归因"。**

形式化：`σ_comp(ω; a, b) = σ_true(ω) + ε_A(a) + ε_B(b) + ε_cross(a, b)`
- a = 连续态侧参数（分波上限、径向网格/匹配、基截断、数值容差）
- b = 靶侧参考参数（活性空间、态数 n、权重 f、Dyson 归一化、关联级别）
- **ε_cross 是解耦也无法消除的部分**，其相对大小决定解耦是否合法。

**四个纠缠机制（决定 ε_cross 不可忽略）**
1. 连续轨道须与束缚轨道正交 → 改靶表示即改连续可用空间；
2. 有效势 V_eff 由靶密度构造 → 靶密度变则交换算符 K 变；
3. 通道数与阈值由靶态定义 → 靶表示决定连续问题的结构；
4. **诊断量本身是两侧的乘积** → ‖V_res G_ref W‖₂ 中 V_res=(V_static−V̄_static)−K 由靶轨道构造、
   G_ref 由连续态侧构造，故 **776.2 无法单独归因**（本项目的直接痛点）。

**关键张力（本轮新增认知，重要）**
- **解耦与"直接以真截面为目标"本质冲突**：要可归因，损失函数就必须能在不调用连续态求解器的
  前提下求值 → **逻辑上必然导致使用代理量（proxy）**。
- 故 Fang 2026 的"代理优化"是解耦的代价，**不是作者疏忽**；上一轮的批评需按此重新定位。
- 张力轴：解耦端（可归因、代理量、成本低） ←→ 耦合端（真量、不可归因、成本高）。
  Fang 2026 位于偏解耦端；全截面联合优化位于耦合端。

**操作定义（本项目 J.4 前置）**
- 实验 A：冻 b₀，只扫 a → ε_A = 求解器噪声 + 基截断地板（必须先建立，否则 ε_B 无意义）；
- 实验 B：冻 a₀，只扫 b → ε_B；
- 共同口径：σ 在能区上的相对 RMSE（须含共振区）；
- 升级规则：若结论随第二因子变动而翻转 → ε_cross 主导，必须做二维联合扫描。

**解耦买不到的**：ε_A/ε_B 的可加性。若改 b 导致通道结构定性改变（新阈值开启），
则在电子结构量上测得的 ε_B 可以很小、而在截面上很大 → **代理型解耦会低估靶侧贡献**。
故正确表述是："解耦买到的是电子结构可控那部分的归因能力，不是精确可加性。"
