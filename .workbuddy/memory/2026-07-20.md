## Dyson轨道量子化学方法综述

使用风暴知识工坊 STORM 多视角研究法，以项目内已有笔记和文献为种子，综述了计算 Dyson 轨道的量子化学方法及配套主流量子化学程序。

### 完成内容
- 五视角 STORM 拆解（实践者/学者/怀疑者/经济学家/历史学家）
- 矛盾图谱：单通道 vs 多通道、PW/CW vs B-spline、EOM-CC vs CASPT2、传播子 vs 显式波函数
- 三大类方法分类：(1) 电子传播子/Green 函数方法（OVGF, P3+, NR2, ADC(n)）(2) EOM-CC 方法（EOM-IP/EA-CCSD, fc-CVS-EOM-CCSD）(3) 多参考方法（MS-CASPT2, CASSCF/CASCI）+ 补充 RCS-ADC 统一框架
- 十个主流量子化学程序的详细说明和接口关系图
- 方法选择决策树
- 同行评审自检

### 关键发现
1. Dyson 轨道方法经历了三阶段演进：Green 函数(1970s-90s) → EOM-CC(2000s-10s) → 多参考+精确连续态(2020s)
2. 连续态描述精度是光电离截面计算的瓶颈，而非 Dyson 轨道本身
3. 单通道 Dyson 近似对主峰足够，多通道耦合需 RCS-ADC 或 R-matrix
4. 软件可用性决定方法影响力：Gaussian EPT 和 Q-Chem/ezDyson 门槛最低

## 三条方法学路线并行深度调查（R-matrix / 复缩放 / Lucchese L²）

使用三个并行子智能体，以与 Decleva 调查相同的六视角 STORM 方法论，独立调查分子连续态量子化学领域三条主要技术路线的历史发展脉络。

### 产出文件
- `notes/R-matrix方法发展脉络深度调查.md` — 747行，从 Wigner 1946 核物理起源到 UKRmol+/RMT/BSR 现代化
- `notes/复缩放方法发展脉络深度调查.md` — 626行，从 Balslev-Combes 1960s 数学物理奠基到 tSURFF 现代扩展
- `notes/Lucchese_L2方法发展脉络深度调查.md` — 688行，从 Caltech 1979 Schwinger 变分法到 LBNL 阿秒科学
- 总计 2061 行

### 关键发现汇总
1. **R-matrix**（Burke 学派）：空间分区（内区/外区）哲学，核心优势在电子碰撞，UKRmol+ 开源，BSR 实现了与 B-spline 的技术融合；传承风险：Burke 和 Zatsarinny 相继离世
2. **复缩放/ECS**（Rescigno-McCurdy 学派）：复坐标旋转将连续态映射为 L² 可积，核心优势在强场电离和三体 Coulomb 破裂精确计算；代码不公开是主要短板；Martín XCHEM 平台延续至欧洲
3. **L²/Schwinger**（Lucchese）：迭代 Schwinger 变分法 + 单中心展开，ePolyScat 代码标志；2017年 Lucchese 从 TAMU 迁至 LBNL 对接阿秒实验；代码"应请求提供"分发模式是可持续性风险

### 四条路线对比定位
四份调查报告（含 Decleva）现构成分子连续态量子化学方法学的完整图谱：
- Decleva B-spline：定态光电离 + TDDFT，Tiresia 代码
- R-matrix：电子碰撞 + 高阶 CI，UKRmol+ 代码
- 复缩放 ECS：强场电离 + 精确三体，无统一代码
- Lucchese L²：单中心精确 SE + Schwinger 变分，ePolyScat 代码
