## 分子连续态量子化学方法系统对比报告

基于此前完成的四份方法学路线深度调查报告，综合形成一份横向对比报告，系统分析 B-spline (Decleva)、R-matrix (Burke-Tennyson)、复缩放 ECS (Rescigno-McCurdy)、L²-Schwinger (Lucchese) 四种方法在光电离截面计算中的优劣性。

### 产出文件
- `notes/分子连续态量子化学方法对比报告.md` — 661行

### 报告结构
1. 对比框架与方法论说明（8个评估维度）
2. 四种方法技术原理对比（连续态处理策略 + 核心技术对比表 + 理论严谨性分析）
3. 光电离截面计算核心维度评分（8维评分矩阵 + 逐维度详细分析）
4. 按物理场景的适用性分析（7个场景：价壳层/内壳层/大分子/PECD/强场阿秒/双光电离/电子碰撞）
5. 代码生态与可用性对比（代码对比矩阵 + 可持续性分析）
6. 方法学局限深层分析（各方法根本局限 + 共性局限）
7. 方法间融合与互补趋势（5个已出现的融合方向 + 互补关系图 + 理想"超级方法"）

10. 同行评审自检（含斯坦福教授评审假设4条质疑及回应）

### 关键结论
- 评分矩阵总分：R-matrix (63) > B-spline (60) > L² (55) > ECS (49)，但等权求和不代表实际应用
- 场景化推荐：定态光电离→B-spline/L²；大分子/PECD→B-spline；强场/阿秒→ECS；双光电离→ECS；电子碰撞→R-matrix；MFPAD→L²
- 四种方法各有根本局限：B-spline=TDDFT双激发盲点；R-matrix=内区维度灾难；ECS=多电子指数墙；L²=单中心球对称限制
- 融合趋势：BSR(B-spline+R-matrix)、XCHEM(ECS+B-spline+阿秒)、Dyson+CASPT2+B-spline

## scansci-pdf 安装配置与下载测试

按照微信文章指引，安装配置了 scansci-pdf 论文下载工具，并以其 Dyson 轨道综述中的补充文献为测试对象。

### 安装配置
- 在隔离 venv 中安装 scansci-pdf v1.9.0（清华镜像源）：`C:\Users\...\envs\scansci\`
- 安装了完整依赖：fast, vpnsci, cloakbrowser, pymupdf, playwright chromium
- MCP 配置已写入 `~/.workbuddy/mcp.json`（scansci-pdf 服务器，command=scansci-pdf.exe, args=["run"]）
- 下载策略配置为 oa_first（用户选择），输出目录设为 `papers/scansci_test/`

### 测试结果
测试了 5 篇 Dyson 综述补充文献 DOI（Moitra 2021, Gozem 2015, Ortiz 2020, Ruberti 2019, Tenorio 2022）：

1. **search 命令**：✅ 完全正常。OpenAlex API 成功返回相关论文列表（DOI、作者、引用数、OA URL）
2. **get 命令（13源竞赛）**：❌ 全部失败。scansci venv 的 Python 3.13.12 存在间歇性 SSL 握手超时（`SSL: UNEXPECTED_EOF_WHILE_READING`），导致 Unpaywall/OpenAlex API 调用失败
3. **fetch 命令（7步机构级联）**：⚠️ 部分工作。成功完成 DOI 解析和 Unpaywall OA 查询，但出版商返回 403 反爬保护，cloakbrowser 运行时下载也因 SSL 超时失败
4. **batch 命令**：❌ 5 篇全部失败，原因同上

### 根因分析
- **SSL 间歇性中断**：scansci venv (Python 3.13.12) 的 SSL 连接不稳定，而系统 miniconda Python 可正常访问相同 API。可能是 Python 3.13 的 SSL 库配置与当前网络环境（可能有防火墙/中间人代理）不兼容
- **出版商反爬**：ACS (403)、MDPI (403)、AIP (403) 均有 Cloudflare 防护，直接 requests 被拦截
- **cloakbrowser 运行时缺失**：需要从 GitHub 下载额外组件但 SSL 超时

### 可用功能
- ✅ 论文搜索（search）：基于 OpenAlex/Semantic Scholar/Crossref
- ✅ MCP 服务器配置：已注册，重启后可用
- ✅ 依赖检查（check）
- ⚠️ 下载功能：受限于此网络环境的 SSL 稳定性

### 建议后续操作
- 重启 WorkBuddy 使 scansci-pdf MCP 服务器生效
- 若需实际下载，建议：1) 配置系统代理解决 SSL 问题；2) 或配置高校 WebVPN（scansci-pdf setup 学校名称）；3) 或在网络更稳定的环境下使用

## USTC WebVPN 配置成功，ACS 论文下载突破

### 配置过程
1. `scansci-pdf setup "中国科学技术大学"` — 配置 WebVPN 网关 `https://wvpn.ustc.edu.cn`
2. `scansci-pdf config-cmd vpnsci_enabled true` — 启用 WebVPN
3. CloakBrowser Chromium 运行时下载（535 MB，从 GitHub）
4. `scansci-pdf login --login-type webvpn` — 打开浏览器，DY 手动完成 USTC CAS 登录
5. Cookie 保存到 `~/.scansci-pdf/cookies/webvpn-cookies.json`

### 修复的 scansci-pdf bug
- **auth.py line 67-68**: `config.get("instsci_base_url", "")` 应为 `config.get("vpnsci_base_url", "")` — 配置键名不匹配导致 WebVPN base URL 为空
- **auth.py line 31**: `config.get("instsci_cookie_file", "")` 应同时检查 `vpnsci_cookie_file` — cookie 路径找不到
- 两个 bug 已直接在 site-packages 中修复
