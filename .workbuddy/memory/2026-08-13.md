## 文献系统 RAG 增强分析

DY 提出文献系统连通器（MCP）不易于让工程模块准确、全面、低幻觉读取的问题。完成系统性诊断：

- **MCP 架构**：`spherical-wave-literature` MCP 基于 `course_material_mcp` 框架，SQLite 存储，纯关键词评分检索（`_score()` 函数：子串匹配 100 分 + token 匹配 10 分 + CJK bigram 1 分），无向量嵌入、无语义检索、无 reranking。
- **核心瓶颈**：检索粒度粗（PDF 按页、Markdown 按 80 行切块）、无 chunk 级元数据、无公式/表格结构化提取、无 project_modules 语义路由、深度调查报告与 Phase G 桥接文档未被 MCP 索引。
- **诊断结论**：当前系统是"关键词 grep + SQLite"而非真正 RAG，幻觉风险源于检索不到 + 检索不准 + 检索碎片化。
- **提出三层增强方案**：L1 语义检索（bge-m3 embedding）、L2 结构化路由（project_modules + phase）、L3 代码上下文注入（Structured Context File），含实施优先级和技术选型建议。
