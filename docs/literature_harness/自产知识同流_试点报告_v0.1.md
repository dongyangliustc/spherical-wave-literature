## 0. 结论（TL;DR）

**闭环跑通，全部验收指标（IC）绿。** 具体为：

1. 自产知识（own_note）与文献知识**同一 ingest 管道**入库（零新增管道）；
2. 每个 chunk 携带 `provenance / epistemic_status / claim_kind` 三轴元数据（fail-closed 默认）；
3. 检索层 epistemic gate 有效拦截未验证主张（`min_epistemic_status`）；
4. `capture_claims.py` 自动从对话文档抽取 14 条原子主张卡并做保守锚定（0 条误升）；
5. 主张 registry（`claims.yaml`）与 review 周报模板打通；
6. 人工升级链路验证：clm-0013 从 `consistent` → `literature_supported` 后，通过 gate 的查询从 0 条变 1 条；
7. 单测 8/8 通过。

## 2. 执行记录

### 2.1 打标规范与 schema（P0 前置）

- **`config/sources.yaml`**：新增 provenance 四值约定（`literature` / `own_publication` / `synth_summary` / `ideation`）；把 `paper-huang-2026-pdcs` 显式标为 `own_publication`（T0*，自有已发表论文，等同 T0 纳入注入门）；追加试点来源 `own-note-pilot-2026-08-26`（`source_type: own_note` → 默认 `ideation/unverified/hypothesis`）。
- **`docs/literature_harness/metadata_schema.md`**：新增"Source-of-Truth Metadata（v0.1）"节，定义维度 A（provenance tier）+ 维度 B（epistemic_status，含 Rank 表与注入门）+ claim_kind（分轨支撑义务）+ 新增 op 内操作字段。

属性默认推断（`sources.py::_infer_defaults`，显式值覆盖）：

| source_type | provenance | epistemic_status | claim_kind |
|---|---|---|---|
| textbook | literature | literature_supported | fact |
| supplementary_textbook | synth_summary | consistent | derivation |
| own_note | ideation | unverified | hypothesis |
| claim_manifest | ideation | unverified | hypothesis |

Epistemic rank（门控判定依据，`store.py::EPISTEMIC_RANK`）：

```
benchmark_verified=3 > literature_supported=2 > consistent=1 > unverified=0
> conflicting=-1 > {refuted, superseded, stale}=-2
```

**注入代码上下文的硬门槛：rank ≥ 2（literature_supported）。**

### 2.2 入库与索引重建

```
python -m course_material_mcp.cli ingest config/sources.yaml
```

结果：**2066 chunks**，三轴分布：

| 轴 | 分布 |
|---|---|
| provenance | synth_summary 685 / literature 1365 / own_publication 13 / **ideation 3** |
| epistemic | consistent 685 / literature_supported 1378 / **unverified 3** |
| claim_kind | derivation 685 / fact 1378 / **hypothesis 3** |

（own-note 试点文档 → 3 chunks，全部 `ideation/unverified/hypothesis`，预期一致。）

### 2.3 检索门控演示（IC-3）

以 **LB94 势渐近行为** 查询为例：

- **普通召回（全量）**：`own-note-pilot...`（ideation/unverified）排第 1 —— 若不设门控，SW Agent 会把未验证主张当事实用。
- **加 `min_epistemic_status='literature_supported'` 后**：ideation chunk 全部拦截，仅保留 Decleva/Stener 等文献命中 → **ideation 召回 = 0**。

### 2.4 主张抽取与保守锚定（IC-4 / IC-5）

`tools/capture_claims.py` 对试点文档抽取 **14 条**原子主张（clm-0002..0015），逐条做锚定：

- 本次修复的**关键缺陷**：首次 dry-run 时所有主张都命中自身 own-note chunk（字面命中 score 128–146 最高），锚定失真。修复策略：
  1. 锚定时**排除 `ideation` provenance 的 chunk**（不自我背书）；
  2. 排除试点来源自身；
  3. 保守三级：仅当锚点是 **T0/T0***（literature / own_publication）且 score ≥ 100 → `literature_supported`；有非 ideation 锚点但弱命中 → `consistent`；无锚点 → `unverified`。
- 修复后结果：**0 条自动达到 `literature_supported`**；有文献弱锚点的工作流/技术类主张 → `consistent`（12 条）；无外部锚点的（clm-0002 workflow 设计共识）→ `unverified`（1 条，留在验证债务队列）。

### 2.5 主张 registry 与人工升级（IC-6）

- `index/registry/claims.yaml`：15 张卡（种子 clm-0001 + 捕获 14 条），字段含 `statement / claim_kind / provenance / epistemic_status / project_module / evidence_chain / anchor_locator / last_verified / reviewer`。
- `query_claims(min_epistemic_status='literature_supported')` 初始 → **0 条**（全部未达标，门控正确）；
- DY 人工核实后，将 **clm-0013**（"可分展开 Schwinger 参照 Lucchese 1986 与 Domcke 1983 构想"）归属升级为 `literature_supported`（Domcke 1983 = separable_potential 核心文献，papers/spherical_wave 实存 PDF）→ 再次查询 **1 条通过**。

### 2.6 合并视角（模块视图）

`query_by_module('separable_potential')` 返回：**4 条文献 + 1 条主张（clm-0013）**，自产主张与文献证据在同一模块视图并列但携带可信度标记。
